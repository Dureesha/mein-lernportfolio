Vorlesung 1 – Einführung in dynamische Webanwendungen und JavaScript

1. Deployment: Installation oder Web-Anwendung

Eine fertig entwickelte Anwendung (z. B. ein Java-Programm mit Swing-GUI) muss zu den Anwendern gelangen. Es gibt zwei Wege:

  • Installation (CD, Download): Die Software muss auf jedem Rechner installiert und aktualisiert werden.
  • Web-Anwendung: Die Anwendung läuft über den Browser und wird zentral bereitgestellt.

2. Software-Architektur von Webanwendungen

Grundlage ist das Client-Server-Modell: Der Webclient (Browser) fordert Dokumente vom Webserver an und stellt sie dar. Je nachdem, wo die Programmlogik liegt, unterscheidet man drei Varianten:

  • Komplett clientseitig (Rich/Thick Client): Der Server liefert die Webseite und eine Java-Anwendung (.jar), die per Java Web Start auf dem Client läuft. Die gesamte Logik liegt beim Client.
  • Komplett serverseitig: Serverprogramme (Java Servlets, CGI, PHP) erzeugen die HTML-Seiten. Beispiel Suchmaschine: Es ist unmöglich, für jeden Suchbegriff fertige HTML-Dokumente vorzuhalten. Die Informationen liegen in einer Datenbank, ein Serverskript fragt sie ab und generiert daraus ein HTML-Dokument.
  • Kombination aus beidem: Der Server liefert statische oder dynamisch erzeugte Seiten (PHP, Java EE, CGI; angebunden sind Datenbanken und externe Systeme). Im Browser verändert JavaScript das Dokument über das Document Object Model (DOM), das dem angezeigten Bild des Browsers entspricht.

Typische Aufgaben von clientseitigem JavaScript: Grafik-Animationen, Formularanpassungen, Plausibilitätschecks, lokale Dialoge, Zugriff auf den lokalen Rechner und asynchrone Interaktivität.

Beispiel: Die Suchvorschläge von Google während der Eingabe entstehen durch JavaScript im Browser.

Wichtig: Java und JavaScript sind zwei eigenständige Sprachen. JavaScript lässt sich auch auf dem Server einsetzen, hat sich dort laut Vorlesungsmaterial aber nicht wirklich durchgesetzt. Serverseitig üblich sind PHP, Perl und Java.

3. Übersetzte, interpretierte und Skriptsprachen

Übersetzung (Compiler)

  • Ein Übersetzer wandelt jedes korrekte Programm der Quellsprache in ein gleichbedeutendes der Zielsprache um, meist Maschinencode einer CPU oder Bytecode einer abstrakten Maschine (JVM).
  • Übersetzte Sprachen haben eine stark ausgeprägte statische Semantik: Typ- und Bindungsregeln werden geprüft, viele Fehler werden schon vor der Ausführung gefunden.

Interpretation

  • Ein Interpretierer liest ein Programm und führt es direkt aus. Typ- und Bindungsregeln werden erst zur Laufzeit geprüft, nicht ausgeführte Programmteile bleiben ungeprüft.
  • Manche Interpretierer (z. B. für PHP und JavaScript) erzeugen vorab eine interne Repräsentation und prüfen so Struktur und einen Teil der Regeln vor der Ausführung.
  • Vorteil: Interpretierer lassen sich in andere Software, z. B. Browser, integrieren. Nachteil: Die Ausführung kann deutlich langsamer sein als bei Maschinencode.

Skriptsprachen

  • Scripting heißt, Kommandos für eine kleine, wiederverwendbare Aufgabe zusammenzusetzen und vorhandene Funktionen zu verknüpfen. Textverarbeitung sowie Ein- und Ausgabe sind wichtig.
  • Eigenschaften: einfache Sprache mit wenigen Konstrukten und Regeln, kurze Programme, dynamische Typprüfung, ohne vorherige Übersetzung ausführbar, leicht erlernbar. Man verzichtet dafür auf die Sicherheit prüfbarer Regeln.
  • Herkunft: Kommandosprachen von Betriebssystemen. Sprachstile: imperativ und objektorientiert.
  • Beispiele: PHP, Perl, JavaScript, Python, Ruby.

4. JavaScript

  • Relativ einfache Skriptsprache, speziell für HTML entwickelt und als Erweiterung von HTML gedacht.
  • Der Code steht im script-Tag direkt im HTML, wird zusammen mit dem HTML per HTTP vom Webserver in den Browser geladen und dort interpretiert.
  • Die Programmiersprache im Web und Basis für dynamisches HTML (DHTML) und Web 2.0.

JavaScript einbinden und ausführen

<script type="text/javascript">
  alert("Hallo Welt! Das ist JavaScript.");
</script>

alert() zeigt ein Hinweisfenster an. Der Code wird beim Laden des Dokuments sofort ausgeführt. Auch Berechnungen sind möglich: 

alert(17 + 5 * 3);

Das Ergebnis ist 32 (Punkt vor Strich). Ohne Anführungszeichen wird gerechnet, mit Anführungszeichen würde der Text ausgegeben.

Auf Benutzereingaben reagieren (Events)

Häufig soll Code erst nach einer Benutzeraktion laufen. Benutzereingaben lösen Ereignisse aus, auf die ein Event-Handler reagiert. Das ist ein zentraler Mechanismus der JavaScript-Programmierung. 

<form>
  <input type="button" value="Test" onclick="alert('Hallo!')">
</form>

Hinter onclick steht der Code, der beim Klick ausgeführt wird. Weil er im HTML-Teil steht, muss er in Anführungszeichen stehen, und innen und außen müssen unterschiedliche Arten (einfach/doppelt) verwendet werden.

Kommentare

Einzeilig mit //, mehrzeilig mit /* ... */. Kommentare werden vom Browser ignoriert und verbessern die Lesbarkeit, besonders bei größeren Programmen, in Teams und beim späteren Wiederlesen.

Browser ohne JavaScript

Nicht jeder Browser oder Nutzer führt JavaScript aus. Der Inhalt des noscript-Tags wird nur angezeigt, wenn kein JavaScript ausgeführt werden kann, z. B. mit dem Hinweis, dass die Seite JavaScript benötigt. Besser ist ein Link auf eine alternative Seite, die auch ohne JavaScript bedienbar ist. 

<noscript>
  <p>Diese Seite benötigt JavaScript.</p>
</noscript>

Vorlesung 2: JavaScript-Grundlagen

Datum: 12.10.2026

In der zweiten Vorlesung ging es um die Grundlagen der JavaScript-Programmierung. Behandelt wurden die Entwicklungsumgebung, Variablen, Datentypen, Operatoren, Arrays, Objekte und Kontrollstrukturen. Außerdem wurden die Inhalte anhand von praktischen Programmierbeispielen erklärt.

1. Entwicklungsumgebung (Folien 3–4)

Visual Studio Code

Visual Studio Code (VS Code) ist ein kostenloser und erweiterbarer Codeeditor von Microsoft. Er funktioniert unter Windows, macOS und Linux. Mit VS Code kann man Programmcode schreiben, bearbeiten und organisieren.

Alternativ wurden die Editoren Atom, Brackets, Notepad++ und BBEdit vorgestellt.

Node.js

Node.js ist eine Laufzeitumgebung für JavaScript. Damit kann JavaScript auch außerhalb eines Browsers ausgeführt werden. Node.js kann beispielsweise für die serverseitige Programmierung (Backend) verwendet werden.

Mit folgenden Befehlen kann überprüft werden, ob Node.js und npm installiert sind: 

node -v
npm -v

2. JavaScript in der Praxis (Folien 5–24)

JavaScript kann HTML-Seiten dynamisch verändern. Beispielsweise können Texte ausgetauscht, Farben verändert und Benutzereingaben verarbeitet werden.

HTML-Inhalte verändern

Mit document.getElementById() wird ein HTML-Element über seine ID ausgewählt. Mit innerHTML kann anschließend dessen Inhalt verändert werden. 

document.getElementById("demo").innerHTML = "Hallo Welt!";

CSS-Eigenschaften verändern

JavaScript kann auch das Aussehen eines HTML-Elements verändern. Mit style.color wird beispielsweise die Textfarbe angepasst. 

document.getElementById("demo").style.color = "red";

JavaScript einbinden

JavaScript kann direkt im HTML-Dokument innerhalb eines script-Elements stehen. Alternativ kann der Code in einer separaten JavaScript-Datei gespeichert und mit src eingebunden werden. 

<script src="script.js"></script>

Eingaben und Ausgaben

  • alert(): Zeigt eine Nachricht in einem Hinweisfenster an.
  • prompt(): Öffnet ein Fenster, in dem Benutzer etwas eingeben können.
  • console.log(): Gibt Informationen in der JavaScript-Konsole aus. 
alert("Hallo!");

let name = prompt("Wie heißt du?");

console.log(name);

Kontrollausgaben und Fehlersuche

Die Browser-Entwicklertools helfen dabei, JavaScript-Programme zu überprüfen. Unter Windows können sie mit F12 geöffnet werden. Auf dem Mac ist beispielsweise die Tastenkombination Command + Option + I möglich.

Mit console.log() können Werte und Zwischenergebnisse ausgegeben werden. Außerdem kann man Breakpoints setzen. Dadurch wird das Programm an einer bestimmten Stelle angehalten und kann schrittweise untersucht werden.

Weitere Konsolenmethoden sind console.error(), console.warn(), console.info() und console.clear().

Strict Mode

Mit "use strict" wird ein strengerer JavaScript-Modus aktiviert. Dadurch werden bestimmte Fehler leichter erkannt. 

"use strict";

3. Variablen und dynamische Typisierung (Folien 25–27)

Variablen werden verwendet, um Werte innerhalb eines Programms zu speichern. JavaScript ist dynamisch typisiert. Das bedeutet, dass der Datentyp einer Variablen nicht vorher festgelegt werden muss.

Eine Variable kann während der Programmausführung auch Werte unterschiedlicher Datentypen speichern. 

let zahl = 5;

zahl = "Hallo";

Die Variable enthält zuerst eine Zahl und danach einen String.

Variablen deklarieren

  • let: Erstellt eine Variable, deren Wert verändert werden kann. Sie ist innerhalb ihres Blocks gültig.
  • const: Erstellt eine Bindung, der kein neuer Wert zugewiesen werden kann. Sie ist ebenfalls blockgebunden.
  • var: Eine ältere Möglichkeit zur Variablendeklaration. Sie besitzt andere Regeln für den Gültigkeitsbereich.

In der Vorlesung wurde besonders die Verwendung von let empfohlen.

4. Werte und Datentypen (Folien 28–39)

Ein Datentyp beschreibt, welche Art von Wert gespeichert wird. Zu den wichtigen Datentypen gehören:

  • Number: Zahlen wie 5 oder 3.5. JavaScript verwendet den Typ Number sowohl für ganze Zahlen als auch für Dezimalzahlen.
  • String: Texte und Zeichenketten, zum Beispiel "Hallo".
  • Boolean: Wahrheitswerte, also true oder false.
  • Object: Objekte, die mehrere Eigenschaften und Werte enthalten.

Datentyp überprüfen

Mit typeof kann der Datentyp eines Wertes überprüft werden. 

let alter = 20;

console.log(typeof alter);

Ausgabe: number

Strings

Strings werden verwendet, um Texte darzustellen. Sie können mit einfachen oder doppelten Anführungszeichen geschrieben werden. 

let text = "Hallo";

let name = 'Anna';

Mit dem Pluszeichen können Strings miteinander verbunden werden. Dies wird als Verkettung bezeichnet. 

let begruessung = "Hallo " + "Welt";

Sonderzeichen können mit einem Backslash geschrieben werden. Beispielsweise steht \n für einen Zeilenumbruch und \t für einen Tabulator.

Template-Literale werden mit Backticks geschrieben. Mit ${...} lassen sich Werte direkt in einen String einfügen. 

let alter = 20;

console.log(`Ich bin ${alter} Jahre alt.`);

Globale und lokale Variablen

Der Gültigkeitsbereich einer Variablen legt fest, an welchen Stellen im Programm auf sie zugegriffen werden kann.

  • Globale Variablen: Werden außerhalb von Funktionen definiert und können in mehreren Bereichen des Programms verwendet werden.
  • Lokale Variablen: Sind nur innerhalb ihres jeweiligen Gültigkeitsbereichs verfügbar.

Bei let und const spielt außerdem der Block zwischen geschweiften Klammern eine wichtige Rolle. 

let x = 10;

function beispiel() {
    let y = 5;

    console.log(x);
    console.log(y);
}

In diesem Beispiel ist x außerhalb der Funktion definiert. Die Variable y ist nur innerhalb der Funktion verfügbar.

5. Arrays (Folien 40–41)

Ein Array ist eine geordnete Liste, in der mehrere Werte gespeichert werden können. 

let farben = ["Rot", "Blau", "Grün"];

Jedes Element besitzt einen Index. Die Zählung beginnt bei 0. 

console.log(farben[0]);

Ausgabe: Rot

Wichtige Array-Methoden

  • push(): Fügt am Ende ein Element hinzu.
  • pop(): Entfernt das letzte Element.
  • shift(): Entfernt das erste Element.
  • unshift(): Fügt vorne ein Element hinzu.
  • sort(): Sortiert die Elemente.
  • reverse(): Kehrt die Reihenfolge um.
  • join(): Verbindet Elemente zu einem String.
  • concat(): Verbindet Arrays.
  • slice(): Gibt einen Ausschnitt zurück.
  • splice(): Entfernt oder ergänzt Elemente.
  • filter(): Filtert Elemente nach einer Bedingung.
  • map(): Erstellt ein Array mit veränderten Werten.
  • forEach(): Durchläuft alle Elemente.
  • reduce(): Fasst Elemente zu einem Wert zusammen.

Beispiel:

let zahlen = [1, 2, 3];

zahlen.push(4);

console.log(zahlen);

Ausgabe: [1, 2, 3, 4]

6. null und undefined (Folie 42)

JavaScript unterscheidet zwischen null und undefined.

  • undefined: Ein Wert wurde noch nicht zugewiesen oder ist nicht vorhanden.
  • null: Beschreibt einen bewusst fehlenden oder leeren Wert. 
let a;

let b = null;

console.log(a);
console.log(b);

7. Operatoren (Folien 43–46)

Operatoren werden verwendet, um Berechnungen durchzuführen, Werte zu vergleichen oder Bedingungen zu verknüpfen.

Arithmetische Operatoren

  • + Addition
  • - Subtraktion
  • * Multiplikation
  • / Division
  • % Rest einer Division
  • ** Potenzierung
  • ++ Erhöhung um 1
  • -- Verringerung um 1

Vergleichsoperatoren

  • == Gleichheit mit möglicher Typumwandlung
  • === Strikte Gleichheit
  • != Ungleichheit
  • !== Strikte Ungleichheit
  • > Größer als
  • < Kleiner als
  • >= Größer oder gleich
  • <= Kleiner oder gleich

Der Unterschied zwischen == und === ist besonders wichtig: Bei === müssen Wert und Datentyp übereinstimmen. 

5 == "5"     // true

5 === "5"    // false

Logische Operatoren

  • && bedeutet UND.
  • || bedeutet ODER.
  • ! bedeutet NICHT.

Weitere behandelte Operatoren sind der bedingte Operator ? : sowie delete, in, instanceof und typeof.

8. Kontrollstrukturen (Folien 47–48)

Kontrollstrukturen bestimmen, welche Anweisungen ausgeführt und welche wiederholt werden.

Bedingungen mit if und else

Mit if wird eine Bedingung überprüft. Ist sie erfüllt, wird der entsprechende Code ausgeführt. Mit else kann ein alternativer Ablauf festgelegt werden. 

let alter = 20;

if (alter >= 18) {
    console.log("Volljährig");
} else {
    console.log("Minderjährig");
}

Schleifen

Schleifen wiederholen bestimmte Anweisungen mehrfach.

  • while: Wiederholt Anweisungen, solange eine Bedingung erfüllt ist.
  • do...while: Führt Anweisungen mindestens einmal aus und prüft die Bedingung danach.
  • for: Eignet sich besonders, wenn Wiederholungen über eine Zählvariable gesteuert werden.

Beispiel einer for-Schleife:

for (let i = 0; i < 5; i++) {
    console.log(i);
}

Ausgabe: 0, 1, 2, 3, 4

Mit geschachtelten Schleifen kann eine Schleife innerhalb einer anderen Schleife ausgeführt werden. Dies ist beispielsweise bei der Sternchen-Dreieck-Aufgabe wichtig.

9. Objekte (Folien 49–51)

Objekte speichern Informationen in Form von Schlüssel-Wert-Paaren. Sie können Eigenschaften und Methoden besitzen.

Eine Eigenschaft speichert einen Wert. Eine Methode ist eine Funktion, die zu einem Objekt gehört. 

const person = {
    vorname: "Max",
    nachname: "Mustermann"
};

console.log(person.vorname);

Auf Eigenschaften kann über die Punktschreibweise oder über eckige Klammern zugegriffen werden. 

person.vorname

person["vorname"]

Objekte können beispielsweise als Objekt-Literal, mit Konstruktorfunktionen oder mit Object.create() erstellt werden.

10. Praktische Übungen (Folien 52–59)

Ausgabe mit Schleifen

In den Übungen wurde gezeigt, wie man mit Schleifen wiederholt Inhalte erzeugen kann. Die Ausgabe kann beispielsweise über console.log() oder innerHTML erfolgen.

Zahlenratespiel

Beim Zahlenratespiel wird mit Math.random() eine Zufallszahl erzeugt. Anschließend gibt der Benutzer mit prompt() eine Zahl ein.

Mit einer while-Schleife kann die Eingabe wiederholt werden, bis die gesuchte Zahl gefunden oder das Spiel abgebrochen wird.

Wichtig ist dabei die Typumwandlung: prompt() gibt eingegebenen Text zunächst als String zurück. JavaScript kann bei bestimmten Operationen automatisch zwischen Datentypen umwandeln.

Wird das Eingabefenster mit "Abbrechen" geschlossen, liefert prompt() normalerweise null.

Bei dieser Aufgabe werden Benutzereingaben, Schleifen und Ausgaben miteinander kombiniert.

  • JavaScript kann im Browser und mit Node.js auch außerhalb des Browsers ausgeführt werden.
  • Variablen speichern Werte und JavaScript verwendet dynamische Typisierung.
  • Arrays speichern mehrere Werte in einer geordneten Liste.
  • Objekte fassen Eigenschaften und Methoden zusammen.
  • Operatoren ermöglichen Berechnungen, Vergleiche und logische Verknüpfungen.
  • Kontrollstrukturen steuern den Ablauf eines Programms.
  • Mit der Konsole und den Entwicklertools können Programme getestet und Fehler gesucht werden.
