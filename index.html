Vorlesung 1: Einführung in dynamische Webanwendungen und JavaScript

1. Deployment: Installation oder Web-Anwendung

Eine fertig entwickelte Anwendung (z. B. ein Java-Programm mit Swing-GUI) muss zu den Anwendern gelangen. Es gibt zwei Wege:

  • Installation (CD, Download): Die Software muss auf jedem Rechner installiert und aktualisiert werden.
  • Web-Anwendung: Die Anwendung läuft über den Browser und wird zentral bereitgestellt.

2. Software-Architektur von Webanwendungen

Grundlage ist das Client-Server-Modell: Der Webclient (Browser) fordert Dokumente vom Webserver an und stellt sie dar. Je nachdem, wo die Programmlogik liegt, unterscheidet man drei Varianten:

  • Komplett clientseitig (Rich/Thick Client): Der Server liefert die Webseite und eine Java-Anwendung (.jar), die per Java Web Start auf dem Client läuft. Die gesamte Logik liegt beim Client.
  • Komplett serverseitig: Serverprogramme (Java Servlets, CGI, PHP) erzeugen die HTML-Seiten. Beispiel Suchmaschine: Es ist unmöglich, für jeden Suchbegriff fertige HTML-Dokumente vorzuhalten. Die Informationen liegen in einer Datenbank, ein Serverskript fragt sie ab und generiert daraus ein HTML-Dokument.
  • Kombination aus beidem: Der Server liefert statische oder dynamisch erzeugte Seiten (PHP, Java EE, CGI; angebunden sind Datenbanken und externe Systeme). Im Browser verändert JavaScript das Dokument über das Document Object Model (DOM), das dem angezeigten Bild des Browsers entspricht.

Typische Aufgaben von clientseitigem JavaScript: Grafik-Animationen, Formularanpassungen, Plausibilitätschecks, lokale Dialoge, Zugriff auf den lokalen Rechner und asynchrone Interaktivität.

Beispiel: Die Suchvorschläge von Google während der Eingabe entstehen durch JavaScript im Browser.

Wichtig: Java und JavaScript sind zwei eigenständige Sprachen. JavaScript lässt sich auch auf dem Server einsetzen, hat sich dort laut Vorlesungsmaterial aber nicht wirklich durchgesetzt. Serverseitig üblich sind PHP, Perl und Java.

3. Übersetzte, interpretierte und Skriptsprachen

Übersetzung (Compiler)

  • Ein Übersetzer wandelt jedes korrekte Programm der Quellsprache in ein gleichbedeutendes der Zielsprache um, meist Maschinencode einer CPU oder Bytecode einer abstrakten Maschine (JVM).
  • Übersetzte Sprachen haben eine stark ausgeprägte statische Semantik: Typ- und Bindungsregeln werden geprüft, viele Fehler werden schon vor der Ausführung gefunden.

Interpretation

  • Ein Interpretierer liest ein Programm und führt es direkt aus. Typ- und Bindungsregeln werden erst zur Laufzeit geprüft, nicht ausgeführte Programmteile bleiben ungeprüft.
  • Manche Interpretierer (z. B. für PHP und JavaScript) erzeugen vorab eine interne Repräsentation und prüfen so Struktur und einen Teil der Regeln vor der Ausführung.
  • Vorteil: Interpretierer lassen sich in andere Software, z. B. Browser, integrieren. Nachteil: Die Ausführung kann deutlich langsamer sein als bei Maschinencode.

Skriptsprachen

  • Scripting heißt, Kommandos für eine kleine, wiederverwendbare Aufgabe zusammenzusetzen und vorhandene Funktionen zu verknüpfen. Textverarbeitung sowie Ein- und Ausgabe sind wichtig.
  • Eigenschaften: einfache Sprache mit wenigen Konstrukten und Regeln, kurze Programme, dynamische Typprüfung, ohne vorherige Übersetzung ausführbar, leicht erlernbar. Man verzichtet dafür auf die Sicherheit prüfbarer Regeln.
  • Herkunft: Kommandosprachen von Betriebssystemen. Sprachstile: imperativ und objektorientiert.
  • Beispiele: PHP, Perl, JavaScript, Python, Ruby.

4. JavaScript

  • Relativ einfache Skriptsprache, speziell für HTML entwickelt und als Erweiterung von HTML gedacht.
  • Der Code steht im script-Tag direkt im HTML, wird zusammen mit dem HTML per HTTP vom Webserver in den Browser geladen und dort interpretiert.
  • Die Programmiersprache im Web und Basis für dynamisches HTML (DHTML) und Web 2.0.

JavaScript einbinden und ausführen

<script type="text/javascript">
  alert("Hallo Welt! Das ist JavaScript.");
</script>

alert() zeigt ein Hinweisfenster an. Der Code wird beim Laden des Dokuments sofort ausgeführt. Auch Berechnungen sind möglich: 

alert(17 + 5 * 3);

Das Ergebnis ist 32 (Punkt vor Strich). Ohne Anführungszeichen wird gerechnet, mit Anführungszeichen würde der Text ausgegeben.

Auf Benutzereingaben reagieren (Events)

Häufig soll Code erst nach einer Benutzeraktion laufen. Benutzereingaben lösen Ereignisse aus, auf die ein Event-Handler reagiert. Das ist ein zentraler Mechanismus der JavaScript-Programmierung. 

<form>
  <input type="button" value="Test" onclick="alert('Hallo!')">
</form>

Hinter onclick steht der Code, der beim Klick ausgeführt wird. Weil er im HTML-Teil steht, muss er in Anführungszeichen stehen, und innen und außen müssen unterschiedliche Arten (einfach/doppelt) verwendet werden.

Kommentare

Einzeilig mit //, mehrzeilig mit /* ... */. Kommentare werden vom Browser ignoriert und verbessern die Lesbarkeit, besonders bei größeren Programmen, in Teams und beim späteren Wiederlesen.

Browser ohne JavaScript

Nicht jeder Browser oder Nutzer führt JavaScript aus. Der Inhalt des noscript-Tags wird nur angezeigt, wenn kein JavaScript ausgeführt werden kann, z. B. mit dem Hinweis, dass die Seite JavaScript benötigt. Besser ist ein Link auf eine alternative Seite, die auch ohne JavaScript bedienbar ist. 

<noscript>
  <p>Diese Seite benötigt JavaScript.</p>
</noscript>

2. JavaScript in der Praxis (Folien 5–24)

JavaScript kann HTML-Seiten dynamisch verändern. Beispielsweise können Texte ausgetauscht, Farben verändert und Benutzereingaben verarbeitet werden.

HTML-Inhalte verändern

Mit document.getElementById() wird ein HTML-Element über seine ID ausgewählt. Mit innerHTML kann anschließend dessen Inhalt verändert werden. 

document.getElementById("demo").innerHTML = "Hallo Welt!";

CSS-Eigenschaften verändern

JavaScript kann auch das Aussehen eines HTML-Elements verändern. Mit style.color wird beispielsweise die Textfarbe angepasst. 

document.getElementById("demo").style.color = "red";

JavaScript einbinden

JavaScript kann direkt im HTML-Dokument innerhalb eines script-Elements stehen. Alternativ kann der Code in einer separaten JavaScript-Datei gespeichert und mit src eingebunden werden. 

<script src="script.js"></script>

Eingaben und Ausgaben

  • alert(): Zeigt eine Nachricht in einem Hinweisfenster an.
  • prompt(): Öffnet ein Fenster, in dem Benutzer etwas eingeben können.
  • console.log(): Gibt Informationen in der JavaScript-Konsole aus. 
alert("Hallo!");

let name = prompt("Wie heißt du?");

console.log(name);

Kontrollausgaben und Fehlersuche

Die Browser-Entwicklertools helfen dabei, JavaScript-Programme zu überprüfen. Unter Windows können sie mit F12 geöffnet werden. Auf dem Mac ist beispielsweise die Tastenkombination Command + Option + I möglich.

Mit console.log() können Werte und Zwischenergebnisse ausgegeben werden. Außerdem kann man Breakpoints setzen. Dadurch wird das Programm an einer bestimmten Stelle angehalten und kann schrittweise untersucht werden.

Weitere Konsolenmethoden sind console.error(), console.warn(), console.info() und console.clear().

Strict Mode

Mit "use strict" wird ein strengerer JavaScript-Modus aktiviert. Dadurch werden bestimmte Fehler leichter erkannt. 

"use strict";

3. Variablen und dynamische Typisierung (Folien 25–27)

Variablen werden verwendet, um Werte innerhalb eines Programms zu speichern. JavaScript ist dynamisch typisiert. Das bedeutet, dass der Datentyp einer Variablen nicht vorher festgelegt werden muss.

Eine Variable kann während der Programmausführung auch Werte unterschiedlicher Datentypen speichern. 

let zahl = 5;

zahl = "Hallo";

Die Variable enthält zuerst eine Zahl und danach einen String.

Variablen deklarieren

  • let: Erstellt eine Variable, deren Wert verändert werden kann. Sie ist innerhalb ihres Blocks gültig.
  • const: Erstellt eine Bindung, der kein neuer Wert zugewiesen werden kann. Sie ist ebenfalls blockgebunden.
  • var: Eine ältere Möglichkeit zur Variablendeklaration. Sie besitzt andere Regeln für den Gültigkeitsbereich.

In der Vorlesung wurde besonders die Verwendung von let empfohlen.

4. Werte und Datentypen (Folien 28–39)

Ein Datentyp beschreibt, welche Art von Wert gespeichert wird. Zu den wichtigen Datentypen gehören:

  • Number: Zahlen wie 5 oder 3.5. JavaScript verwendet den Typ Number sowohl für ganze Zahlen als auch für Dezimalzahlen.
  • String: Texte und Zeichenketten, zum Beispiel "Hallo".
  • Boolean: Wahrheitswerte, also true oder false.
  • Object: Objekte, die mehrere Eigenschaften und Werte enthalten.

Datentyp überprüfen

Mit typeof kann der Datentyp eines Wertes überprüft werden. 

let alter = 20;

console.log(typeof alter);

Ausgabe: number

Strings

Strings werden verwendet, um Texte darzustellen. Sie können mit einfachen oder doppelten Anführungszeichen geschrieben werden. 

let text = "Hallo";

let name = 'Anna';

Mit dem Pluszeichen können Strings miteinander verbunden werden. Dies wird als Verkettung bezeichnet. 

let begruessung = "Hallo " + "Welt";

Sonderzeichen können mit einem Backslash geschrieben werden. Beispielsweise steht \n für einen Zeilenumbruch und \t für einen Tabulator.

Template-Literale werden mit Backticks geschrieben. Mit ${...} lassen sich Werte direkt in einen String einfügen. 

let alter = 20;

console.log(`Ich bin ${alter} Jahre alt.`);

Globale und lokale Variablen

Der Gültigkeitsbereich einer Variablen legt fest, an welchen Stellen im Programm auf sie zugegriffen werden kann.

  • Globale Variablen: Werden außerhalb von Funktionen definiert und können in mehreren Bereichen des Programms verwendet werden.
  • Lokale Variablen: Sind nur innerhalb ihres jeweiligen Gültigkeitsbereichs verfügbar.

Bei let und const spielt außerdem der Block zwischen geschweiften Klammern eine wichtige Rolle. 

let x = 10;

function beispiel() {
    let y = 5;

    console.log(x);
    console.log(y);
}

In diesem Beispiel ist x außerhalb der Funktion definiert. Die Variable y ist nur innerhalb der Funktion verfügbar.

5. Arrays (Folien 40–41)

Ein Array ist eine geordnete Liste, in der mehrere Werte gespeichert werden können. 

let farben = ["Rot", "Blau", "Grün"];

Jedes Element besitzt einen Index. Die Zählung beginnt bei 0. 

console.log(farben[0]);

Ausgabe: Rot

Wichtige Array-Methoden

  • push(): Fügt am Ende ein Element hinzu.
  • pop(): Entfernt das letzte Element.
  • shift(): Entfernt das erste Element.
  • unshift(): Fügt vorne ein Element hinzu.
  • sort(): Sortiert die Elemente.
  • reverse(): Kehrt die Reihenfolge um.
  • join(): Verbindet Elemente zu einem String.
  • concat(): Verbindet Arrays.
  • slice(): Gibt einen Ausschnitt zurück.
  • splice(): Entfernt oder ergänzt Elemente.
  • filter(): Filtert Elemente nach einer Bedingung.
  • map(): Erstellt ein Array mit veränderten Werten.
  • forEach(): Durchläuft alle Elemente.
  • reduce(): Fasst Elemente zu einem Wert zusammen.

Beispiel:

let zahlen = [1, 2, 3];

zahlen.push(4);

console.log(zahlen);

Ausgabe: [1, 2, 3, 4]

6. null und undefined (Folie 42)

JavaScript unterscheidet zwischen null und undefined.

  • undefined: Ein Wert wurde noch nicht zugewiesen oder ist nicht vorhanden.
  • null: Beschreibt einen bewusst fehlenden oder leeren Wert. 
let a;

let b = null;

console.log(a);
console.log(b);

7. Operatoren (Folien 43–46)

Operatoren werden verwendet, um Berechnungen durchzuführen, Werte zu vergleichen oder Bedingungen zu verknüpfen.

Arithmetische Operatoren

  • + Addition
  • - Subtraktion
  • * Multiplikation
  • / Division
  • % Rest einer Division
  • ** Potenzierung
  • ++ Erhöhung um 1
  • -- Verringerung um 1

Vergleichsoperatoren

  • == Gleichheit mit möglicher Typumwandlung
  • === Strikte Gleichheit
  • != Ungleichheit
  • !== Strikte Ungleichheit
  • > Größer als
  • < Kleiner als
  • >= Größer oder gleich
  • <= Kleiner oder gleich

Der Unterschied zwischen == und === ist besonders wichtig: Bei === müssen Wert und Datentyp übereinstimmen. 

5 == "5"     // true

5 === "5"    // false

Logische Operatoren

  • && bedeutet UND.
  • || bedeutet ODER.
  • ! bedeutet NICHT.

Weitere behandelte Operatoren sind der bedingte Operator ? : sowie delete, in, instanceof und typeof.

8. Kontrollstrukturen (Folien 47–48)

Kontrollstrukturen bestimmen, welche Anweisungen ausgeführt und welche wiederholt werden.

Bedingungen mit if und else

Mit if wird eine Bedingung überprüft. Ist sie erfüllt, wird der entsprechende Code ausgeführt. Mit else kann ein alternativer Ablauf festgelegt werden. 

let alter = 20;

if (alter >= 18) {
    console.log("Volljährig");
} else {
    console.log("Minderjährig");
}

Schleifen

Schleifen wiederholen bestimmte Anweisungen mehrfach.

  • while: Wiederholt Anweisungen, solange eine Bedingung erfüllt ist.
  • do...while: Führt Anweisungen mindestens einmal aus und prüft die Bedingung danach.
  • for: Eignet sich besonders, wenn Wiederholungen über eine Zählvariable gesteuert werden.

Beispiel einer for-Schleife:

for (let i = 0; i < 5; i++) {
    console.log(i);
}

Ausgabe: 0, 1, 2, 3, 4

Mit geschachtelten Schleifen kann eine Schleife innerhalb einer anderen Schleife ausgeführt werden. Dies ist beispielsweise bei der Sternchen-Dreieck-Aufgabe wichtig.

const person = {

console.log(person.vorname);

Auf Eigenschaften kann über die Punktschreibweise oder über eckige Klammern zugegriffen werden. 

person.vorname

person["vorname"]

Objekte können beispielsweise als Objekt-Literal, mit Konstruktorfunktionen oder mit Object.create() erstellt werden.

Teil 1: JavaScript-Grundlagen

1. Funktionen in JavaScript (Folien 2–4)

Eine Funktion ist ein wiederverwendbarer Programmabschnitt, der eine bestimmte Aufgabe ausführt. Funktionen können Eingabewerte erhalten, diese verarbeiten und anschließend ein Ergebnis zurückgeben.

JavaScript behandelt Funktionen als Werte. Das bedeutet, dass Funktionen auch Variablen zugewiesen, an andere Funktionen übergeben oder von Funktionen zurückgegeben werden können. Man spricht dabei von First-Class Functions.

Funktionen können auf verschiedene Arten erstellt werden:

  • Mit einer Funktionsanweisung (Function Statement)
  • Mit einem Funktionsausdruck (Function Expression)
  • Mit dem Konstruktor des Function-Objekts
  • Mit einer Pfeilfunktion (Arrow Function)

1.1 Funktionsanweisung

Bei einer Funktionsanweisung wird die Funktion mit dem Schlüsselwort function und einem Namen definiert. Die Werte in den Klammern heißen Parameter. Mit return wird ein Ergebnis zurückgegeben. 

function add(number1, number2) {
    return number1 + number2;
}

console.log(add(2, 3));
// Ausgabe: 5

JavaScript legt bei dieser Funktion nicht automatisch fest, dass die Parameter Zahlen sein müssen. Werden zwei Strings übergeben, kann das Pluszeichen diese miteinander verbinden. Deshalb kann eine Typprüfung sinnvoll sein. 

function add(number1, number2) {
    if (typeof number1 != "number" ||
        typeof number2 != "number") {
        throw new TypeError("Parameter müssen Zahlen sein.");
    }

    return number1 + number2;
}

1.2 Funktionsausdruck

Bei einem Funktionsausdruck wird eine Funktion direkt einer Variablen zugewiesen. Die Funktion kann dabei einen eigenen Namen besitzen oder anonym sein. 

const add = function(number1, number2) {
    return number1 + number2;
};

console.log(add(4, 5));
// Ausgabe: 9

Eine anonyme Funktion besitzt keinen eigenen Namen. Sie kann trotzdem über die Variable aufgerufen werden, in der sie gespeichert ist.

2. Pfeilfunktionen (Folien 5–9)

Pfeilfunktionen wurden mit ES2015 eingeführt. Sie sind eine kürzere Schreibweise für Funktionen. Statt des Schlüsselworts function verwendet man den Pfeil =>.

Eine normale Funktion:

const hello = function() {
    return "Hallo Welt!";
};

Dieselbe Funktion als Pfeilfunktion:

const hello = () => {
    return "Hallo Welt!";
};

Besteht der Funktionskörper nur aus einem Ausdruck, dessen Wert zurückgegeben werden soll, können die geschweiften Klammern und return entfallen. 

const hello = () => "Hallo Welt!";

2.1 Pfeilfunktion mit einem Parameter

Hat eine Pfeilfunktion genau einen einfachen Parameter, dürfen die runden Klammern weggelassen werden. 

const square1 = (x) => {
    return x * x;
};

const square2 = x => x * x;

console.log(square2(4));
// Ausgabe: 16

2.2 Pfeilfunktion ohne Parameter

Wenn eine Funktion keine Parameter benötigt, muss ein leeres Klammerpaar geschrieben werden. 

const horn = () => {
    console.log("Toot");
};

horn();

2.3 Funktionen aufrufen

Eine Funktion wird mit ihrem Namen und runden Klammern aufgerufen. Innerhalb der Klammern stehen die übergebenen Argumente. 

const add = (x, y) => x + y;

console.log(add(2, 2));
// Ausgabe: 4

console.log(add("Hallo ", "Welt"));
// Ausgabe: Hallo Welt

Wichtig ist, dass der Plusoperator sowohl Zahlen addieren als auch Strings verketten kann. Pfeilfunktionen unterscheiden sich außerdem von normalen Funktionen beim sogenannten this-Binding.

3. Parameter und Argumente (Folien 10–16)

Parameter sind die Variablen, die bei der Definition einer Funktion angegeben werden. Argumente sind die tatsächlichen Werte, die beim Aufruf übergeben werden. 

function add(a, b) {
    return a + b;
}

add(2, 5);

In diesem Beispiel sind a und b die Parameter. Die Zahlen 2 und 5 sind die Argumente.

3.1 Das arguments-Objekt

Bei normalen Funktionen stellt JavaScript das Objekt arguments bereit. Darin stehen die übergebenen Argumente.

Man kann mit einem Index auf einzelne Argumente zugreifen und mit arguments.length ihre Anzahl bestimmen. 

function addAll() {
    let result = 0;

    for (let i = 0; i < arguments.length; i++) {
        result += arguments[i];
    }

    return result;
}

console.log(addAll(1, 2, 3));
// Ausgabe: 6

arguments ähnelt einem Array, ist aber kein echtes Array. Deshalb können nicht alle Array-Methoden direkt darauf angewendet werden. Pfeilfunktionen besitzen kein eigenes arguments-Objekt.

3.2 Rest-Parameter

Seit ES2015 gibt es Rest-Parameter. Sie werden mit drei Punkten ... geschrieben und sammeln mehrere übergebene Argumente in einem Array. 

function addAll(...numbers) {
    let result = 0;

    for (let i = 0; i < numbers.length; i++) {
        result += numbers[i];
    }

    return result;
}

console.log(addAll(2, 3, 4));
// Ausgabe: 9

Rest-Parameter sind besonders hilfreich, wenn vorher nicht bekannt ist, wie viele Argumente übergeben werden. Sie stehen am Ende der Parameterliste.

4. Spread-Operator (Folien 17–24)

Der Spread-Operator wird ebenfalls mit drei Punkten ... geschrieben. Seine Aufgabe ist aber anders als bei Rest-Parametern.

  • Rest: Sammelt mehrere Werte zu einem Array.
  • Spread: Verteilt die Elemente eines Arrays oder die Eigenschaften eines Objekts.

4.1 Arrays erweitern

Mit Spread können die Elemente eines Arrays in ein neues Array eingefügt werden. 

let zahlen = [1, 2, 3];

let neueZahlen = [...zahlen, 4, 5];

console.log(neueZahlen);
// Ausgabe: [1, 2, 3, 4, 5]

4.2 Arrays zusammenfügen

let array1 = ["Rot", "Blau"];
let array2 = ["Grün", "Gelb"];

let farben = [...array1, ...array2];

console.log(farben);
// Ausgabe: ["Rot", "Blau", "Grün", "Gelb"]

4.3 Objekte zusammenfügen

Mit Spread können auch Eigenschaften verschiedener Objekte in einem neuen Objekt zusammengefasst werden. 

let person = {
    name: "Anna",
    alter: 20
};

let adresse = {
    stadt: "Mannheim"
};

let daten = {...person, ...adresse};

console.log(daten);

Das neue Objekt enthält die Eigenschaften name, alter und stadt. Bei gleichen Eigenschaftsnamen überschreibt ein späterer Wert den vorherigen.

4.4 Kopieren und Referenzen

Bei Arrays und Objekten ist wichtig, zwischen einer Referenz und einer Kopie zu unterscheiden.

Wenn eine Objektvariable einer anderen zugewiesen wird, verweisen beide Variablen auf dasselbe Objekt. Eine Änderung ist deshalb über beide Variablen sichtbar. 

let person1 = {name: "Anna"};

let person2 = person1;

person1.name = "Lisa";

console.log(person2.name);
// Ausgabe: Lisa

Mit Spread kann dagegen ein neues Objekt erstellt werden. 

let person1 = {name: "Anna"};

let person2 = {...person1};

person1.name = "Lisa";

console.log(person2.name);
// Ausgabe: Anna

Diese Kopie ist allerdings nur eine flache Kopie. Enthält das Objekt weitere verschachtelte Objekte, können deren Referenzen weiterhin gemeinsam verwendet werden.

5. Funktionen als Werte (Folie 25)

Da Funktionen in JavaScript Werte sind, können sie in Variablen gespeichert und anderen Variablen zugewiesen werden.

Bei einer mit let deklarierten Variablen kann sogar später eine andere Funktion gespeichert werden. 

let begruessung = function() {
    console.log("Hallo!");
};

begruessung();

begruessung = function() {
    console.log("Guten Morgen!");
};

begruessung();

Dadurch kann sich ändern, welcher Programmcode beim Aufruf einer Funktionsvariablen ausgeführt wird.

6. Seiteneffekte und reine Funktionen (Folien 26–29)

Funktionen können einen Rückgabewert liefern oder einen Seiteneffekt auslösen. Beides ist auch gleichzeitig möglich.

6.1 Seiteneffekte

Ein Seiteneffekt liegt vor, wenn eine Funktion etwas außerhalb ihres eigenen Rückgabewerts verändert oder eine von außen beobachtbare Aktion ausführt.

Beispiele sind:

  • Eine globale Variable verändern
  • Den Zustand einer Anwendung ändern
  • Eine Ausgabe mit console.log() erzeugen

6.2 Reine Funktionen (Pure Functions)

Eine reine Funktion liefert bei denselben Eingabewerten immer dasselbe Ergebnis. Sie verursacht keine Seiteneffekte und verändert keine Daten außerhalb der Funktion. 

const add = (a, b) => a + b;

console.log(add(2, 3));
// Ausgabe: 5

Die Funktion add ist rein, weil ihr Ergebnis nur von den Parametern abhängt und sie selbst nichts verändert.

6.3 Beispiel mit einem Objekt

const peter = {
    name: "Peter Smith",
    hasCar: false
};

const buyCar = (person) => ({
    ...person,
    hasCar: true
});

console.log(buyCar(peter));
// Neues Objekt mit hasCar: true

console.log(peter);
// Ursprüngliches Objekt mit hasCar: false

Die Funktion erstellt mit Spread ein neues Objekt, anstatt das ursprüngliche Objekt zu verändern. Das ist ein Beispiel für eine reine Funktion.

Reine Funktionen sind leichter zu testen, weil ihr Ergebnis vorhersehbar ist. Trotzdem sind Seiteneffekte nicht immer schlecht. Manche Aufgaben benötigen sie, zum Beispiel Ausgaben oder Änderungen an einer Webseite.

7. Higher-Order-Functions (Folien 30–34)

Higher-Order-Functions sind Funktionen, die andere Funktionen als Argument entgegennehmen oder selbst eine Funktion zurückgeben.

Beispiele sind die Array-Methoden map(), filter() und reduce().

7.1 Funktionen als Argumente

const invokeIf = (condition, ifTrue, ifFalse) => {
    condition ? ifTrue() : ifFalse();
};

const showWelcome = () => {
    console.log("Welcome!");
};

const showError = () => {
    console.log("Error!");
};

invokeIf(true, showWelcome, showError);
// Ausgabe: Welcome!

invokeIf erhält eine Bedingung und zwei Funktionen. Je nachdem, ob die Bedingung wahr oder falsch ist, wird eine der Funktionen aufgerufen.

7.2 Eine Funktion zurückgeben

function wrapValue(n) {
    let local = n;

    return () => local;
}

let wrap1 = wrapValue(1);
let wrap2 = wrapValue(2);

console.log(wrap1());
// Ausgabe: 1

console.log(wrap2());
// Ausgabe: 2

wrapValue gibt eine neue Funktion zurück. Diese kann sich den Wert der lokalen Variable merken, auch nachdem der ursprüngliche Funktionsaufruf beendet ist. Dieses Verhalten hängt mit dem Konzept einer Closure zusammen.

8. Praktische Übung: Bohnen zählen (Folie 35)

Als Abgabe sollten wir die Funktion countBs mithilfe von Pfeilfunktionen schreiben und das laufende Programm zusammen mit dem Quellcode vorzeigen. Alternativ war eine Bildschirmaufnahme möglich.

Die Aufgabe besteht darin, in einem Text die Anzahl der großen Buchstaben B zu zählen. Mit einer allgemeineren Funktion countChar kann man auch andere Zeichen zählen. 

const countChar = (text, zeichen) => {
    let anzahl = 0;

    for (let i = 0; i < text.length; i++) {
        if (text[i] == zeichen) {
            anzahl++;
        }
    }

    return anzahl;
};

const countBs = (text) => {
    return countChar(text, "B");
};

console.log(countBs("BBohnen"));
// Ausgabe: 2

console.log(countChar("Hallo", "l"));
// Ausgabe: 2

Bei dieser Übung werden Pfeilfunktionen, Parameter, Rückgabewerte, Bedingungen und Schleifen miteinander kombiniert.

Teil 2: Einführung in HTML – Hypertext und Links

9. Was ist Hypertext? (Folien 2–4)

HTML bedeutet HyperText Markup Language. HTML ist eine Auszeichnungssprache, mit der die Struktur von Webseiten beschrieben wird.

Der Begriff Hypertext bedeutet, dass Texte miteinander verknüpft werden können. Durch Hyperlinks kann man von einer Webseite zu einer anderen wechseln.

Links sind damit eine wichtige Grundlage für die Navigation im World Wide Web.

10. Hyperlinks erstellen (Folien 5–18)

In HTML werden Links mit dem a-Element erstellt. Das a steht für Anchor.

Der Text zwischen dem öffnenden und schließenden a-Tag wird als anklickbarer Link angezeigt. 

<a href="elixire.html">Elixiere</a>

Das Attribut href gibt an, wohin der Link führen soll. Wenn der Benutzer auf den Link klickt, öffnet der Browser die angegebene Zielseite.

Im Vorlesungsbeispiel wurde die Webseite einer fiktiven KopfÜBar um Links erweitert.

Die Hauptseite bar.html sollte beispielsweise auf eine Seite mit Elixieren und auf eine Wegbeschreibung verlinken. 

<a href="elixir.html">Elixiere</a>

<a href="wegbeschreibung.html">Wegbeschreibung</a>

Nach dem Speichern wurden die Links im Browser getestet. Dabei wurde überprüft, ob die richtige Seite geöffnet wird und ob man mit der Zurück-Taste wieder zur Hauptseite gelangt.

11. HTML-Attribute (Folien 19–23)

Attribute geben zusätzliche Informationen zu HTML-Elementen an. Sie stehen im öffnenden Tag.

Beispiele:

<a href="seite.html">Link</a>

<img src="bild.jpg">

<style type="text/css">
  • href: Gibt das Ziel eines Hyperlinks an.
  • src: Gibt die Quelle einer Datei an, beispielsweise eines Bildes.
  • type: Beschreibt bei entsprechenden Elementen den Typ des Inhalts.

Attribute bestehen normalerweise aus einem Namen, einem Gleichheitszeichen und einem Wert in Anführungszeichen.

Im Vorlesungsmaterial wird empfohlen, Attributwerte immer in Anführungszeichen zu schreiben.

HTML-Elemente unterstützen nur bestimmte Attribute. Man sollte deshalb die vorgesehenen Attribute für das jeweilige Element verwenden.

12. Weitere Möglichkeiten mit Links (Folien 24–26)

Links können auch verwendet werden, um von einer Unterseite zurück zur Hauptseite zu gelangen. 

<a href="bar.html">Zurück zur Hauptseite</a>

Außerdem können Bilder als Links verwendet werden. Dazu wird ein img-Element innerhalb eines a-Elements platziert. 

<a href="bar.html">
    <img src="bild.jpg" alt="Zur Hauptseite">
</a>

Nicht jedes HTML-Element eignet sich dafür, direkt innerhalb eines Links verwendet zu werden. Entscheidend ist, welche Inhalte im a-Element erlaubt sind.

13. Webseiten mit Ordnern organisieren (Folien 27–31)

Wenn eine Webseite größer wird, ist es unübersichtlich, alle Dateien in einem einzigen Ordner zu speichern.

Deshalb sollte man die Dateien sinnvoll auf verschiedene Unterordner verteilen.

Im Beispiel der KopfÜBar wurde die Webseite folgendermaßen organisiert: 

bar/
    bar.html

    info/
        wegbeschreibung.html

    getraenke/
        elixir.html

    bilder/
        getraenke.gif
        rot.jpg
        gruen.jpg

Der Ordner bar ist das Hauptverzeichnis der Webseite. Die HTML-Dateien und Bilder werden nach ihrem Inhalt in Unterordner aufgeteilt.

Diese Organisation erleichtert die Übersicht und die spätere Erweiterung der Webseite.

14. Relative Dateipfade (Folien 32–44)

Wenn Dateien verschoben werden, funktionieren alte Links möglicherweise nicht mehr. Der Grund ist, dass sich die Speicherorte geändert haben.

Ein relativer Pfad beschreibt den Weg von der aktuellen Datei zu einer anderen Datei.

14.1 Datei im gleichen Ordner

Befinden sich zwei Dateien im selben Ordner, genügt der Dateiname. 

<a href="seite.html">Seite öffnen</a>

14.2 Datei in einem Unterordner

Liegt die Zieldatei in einem Unterordner, wird zuerst der Ordnername und dann der Dateiname angegeben. 

<a href="getraenke/elixir.html">Elixiere</a>

Der Schrägstrich trennt die einzelnen Ordner und Dateien.

14.3 Eine Ordnerebene nach oben

Mit ../ geht man im Verzeichnisbaum eine Ebene nach oben.

Befindet man sich beispielsweise in getraenke/elixir.html und möchte zur Hauptseite bar.html zurückkehren, verwendet man: 

<a href="../bar.html">Zurück zur Bar</a>

14.4 Zwei Ordnerebenen nach oben

Für jede weitere Ebene nach oben wird ein zusätzliches ../ verwendet. 

<a href="../../index.html">Startseite</a>

Relative Pfade hängen immer vom Speicherort der aktuellen Datei ab. Deshalb muss man zuerst den Ausgangspunkt und das Ziel bestimmen.

15. Relative Pfade bei Bildern (Folien 45–48)

Nicht nur Links, sondern auch Bilder benötigen den richtigen Dateipfad.

Wenn ein Bild in einen Unterordner verschoben wird, muss das src-Attribut angepasst werden.

Vorher:

<img src="getraenke.gif" alt="Getränke">

Nach dem Verschieben in den Ordner bilder:

<img src="bilder/getraenke.gif" alt="Getränke">

Wenn eine HTML-Datei selbst in einem Unterordner liegt, muss auch der Pfad zum Bild entsprechend angepasst werden. 

<img src="../bilder/rot.jpg" alt="Rotes Getränk">

In diesem Beispiel geht der Browser zuerst eine Ebene nach oben und anschließend in den Ordner bilder.

16. Praktische Übungen zu HTML (Folien 9–13, 24–25, 31, 38, 48)

Im HTML-Teil gab es mehrere Übungen zur Navigation und Dateiorganisation.

  • Links von der Hauptseite zu anderen HTML-Seiten erstellen.
  • Links zum Zurückkehren auf die Hauptseite ergänzen.
  • Die Webseite in die Ordner info, getraenke und bilder aufteilen.
  • Nach dem Verschieben der Dateien fehlerhafte Links erkennen.
  • Relative Pfade mit ../ richtig angeben.
  • Bildpfade an die neue Ordnerstruktur anpassen.
  • Alle Änderungen im Browser testen.

17. Relativität als Herausforderung (Folien 49–55)

Zum Abschluss wurde noch einmal deutlich gemacht, dass relative Pfade bei größeren Webseiten schnell unübersichtlich werden können.

Entscheidend ist immer, von welcher Datei aus ein Pfad angegeben wird. Derselbe Dateiname kann je nach Ausgangspunkt einen anderen Pfad benötigen.

Deshalb ist eine klare Ordnerstruktur wichtig. Am Ende der Unterlagen gab es außerdem ein HTML-Kreuzworträtsel zur Wiederholung der Begriffe.

Zusammenfassung meiner wichtigsten Erkenntnisse

  • Funktionen helfen dabei, Programmcode wiederzuverwenden.
  • Pfeilfunktionen ermöglichen eine kürzere Schreibweise.
  • Parameter stehen in der Funktionsdefinition, Argumente werden beim Aufruf übergeben.
  • Rest-Parameter sammeln Werte, während Spread Werte verteilt.
  • Reine Funktionen verändern keine Daten außerhalb der Funktion.
  • Higher-Order-Functions können andere Funktionen entgegennehmen oder zurückgeben.
  • Hyperlinks verbinden Webseiten miteinander.
  • Das href-Attribut legt das Ziel eines Links fest.
  • Ordnerstrukturen sorgen für eine bessere Übersicht.
  • Relative Pfade müssen immer vom aktuellen Speicherort aus betrachtet werden.

Teil 1: JavaScript – Strings und Formulare

1. Strings

Ein String ist eine Zeichenkette, also ein Text. Strings können in JavaScript direkt mit Anführungszeichen erstellt werden. Alternativ gibt es den String-Konstruktor. 

let text = "Hallo Welt";
let text2 = new String("Hallo Welt");

2. Wichtige String-Methoden

Mit String-Methoden können Texte untersucht, durchsucht und in einzelne Teile zerlegt werden.

  • charAt(index): Gibt ein Zeichen an einer bestimmten Position zurück.
  • indexOf(text): Findet die erste Position eines gesuchten Textes.
  • lastIndexOf(text): Findet die letzte Position eines gesuchten Textes.
  • substring(start, ende): Gibt einen bestimmten Teil eines Strings zurück.
  • split(trennzeichen): Zerlegt einen String in ein Array.
  • length: Gibt die Länge einer Zeichenkette an.
let text = "Hallo Welt";

text.charAt(0);        // "H"
text.indexOf("Welt");  // 6
text.substring(0, 5);  // "Hallo"
text.split(" ");       // ["Hallo", "Welt"]
text.length;           // 10

Wichtig ist, dass die Zählung bei 0 beginnt. Wird ein gesuchter Text nicht gefunden, liefert indexOf() den Wert -1. Bei substring() ist die Endposition nicht enthalten. length ist eine Eigenschaft und keine Methode.

3. Das Document Object Model (DOM)

Das DOM stellt die HTML-Elemente einer Webseite als Objekte dar. JavaScript kann dadurch auf einzelne Elemente zugreifen und deren Inhalte oder Eigenschaften verändern.

Beispielsweise können Texte ausgelesen, Eingabewerte verarbeitet und Formulare verändert werden.

4. Formulare in JavaScript

HTML-Formulare ermöglichen es Benutzern, Daten auf einer Webseite einzugeben. Mit JavaScript können diese Eingaben ausgelesen und weiterverarbeitet werden.

Ein Formular wird mit dem form-Element erstellt. Über das Attribut name können Formulare und Eingabefelder angesprochen werden. 

<form name="meinFormular">
    <input type="text" name="eingabe">
</form>

Mit der Eigenschaft value kann JavaScript den Wert eines Eingabefeldes lesen oder verändern. 

document.meinFormular.eingabe.value

5. Wichtige Formularelemente

  • Text: Ein Eingabefeld für Text.
  • Password: Verdeckt die eingegebenen Zeichen.
  • Hidden: Ein unsichtbares Eingabefeld.
  • Button: Eine Schaltfläche für Benutzeraktionen.
  • Submit: Sendet ein Formular ab.
  • Reset: Setzt Eingabefelder auf ihre Anfangswerte zurück.
  • Checkbox: Ermöglicht mehrere unabhängige Auswahlen.
  • Radio: Ermöglicht die Auswahl einer Option innerhalb einer Gruppe.
  • Select: Erstellt eine Auswahlliste.

Bei Checkboxen und Radio-Buttons kann mit checked überprüft werden, ob sie ausgewählt sind.

Bei Auswahllisten sind die Eigenschaften options und selectedIndex wichtig. Mit selected kann eine Option vorausgewählt werden.

Teil 2: HTML – Aufbau und Struktur

6. Aufbau einer HTML-Seite

HTML steht für HyperText Markup Language. Mit HTML wird die Struktur und Bedeutung der Inhalte einer Webseite festgelegt.

Eine Webseite sollte zuerst geplant werden, damit die Inhalte sinnvoll angeordnet sind. Dafür können Überschriften, Absätze, Bilder und weitere HTML-Elemente verwendet werden.

7. Wichtige HTML-Elemente

  • html: Enthält das gesamte HTML-Dokument.
  • head: Enthält Informationen über die Webseite.
  • body: Enthält den sichtbaren Inhalt.
  • h1 bis h6: Überschriften in verschiedenen Ebenen.
  • p: Kennzeichnet einen Absatz.
  • img: Fügt ein Bild ein.
  • br: Erzeugt einen Zeilenumbruch.
  • q: Kennzeichnet ein kurzes Zitat.
  • blockquote: Kennzeichnet ein längeres Zitat.
  • em: Hebt einen Text inhaltlich hervor.
  • strong: Kennzeichnet besonders wichtige Inhalte.

HTML beschreibt hauptsächlich die Struktur und Bedeutung der Inhalte. Die optische Gestaltung erfolgt mit CSS.

8. HTML-Elemente richtig verwenden

HTML-Elemente sollten passend zum Inhalt ausgewählt und richtig verschachtelt werden. Dadurch wird die Webseite übersichtlicher und der Code leichter verständlich.

Beispielsweise werden Überschriften mit h1 bis h6 gekennzeichnet und normale Textabsätze mit p. Für tabellarische Daten können HTML-Tabellen verwendet werden.

Teil 3: CSS – Gestaltung von Webseiten

9. Was ist CSS?

CSS steht für Cascading Style Sheets. Mit CSS wird das Aussehen einer Webseite gestaltet, zum Beispiel Farben, Schriftarten, Abstände und Rahmen.

Eine CSS-Regel besteht aus einem Selektor und einer oder mehreren Deklarationen. Eine Deklaration enthält eine Eigenschaft und den dazugehörigen Wert. 

p {
    color: purple;
    background-color: pink;
}

Der Selektor p spricht alle p-Elemente an. color legt die Textfarbe fest und background-color die Hintergrundfarbe.

10. CSS in HTML einbinden

CSS kann direkt im HTML-Dokument innerhalb eines style-Elements im head-Bereich stehen. 

<style>
    h1 {
        color: purple;
    }
</style>

Alternativ kann CSS in einer separaten Datei gespeichert werden. Diese wird mit dem link-Element eingebunden. 

<link rel="stylesheet" href="style.css">

Eine externe CSS-Datei ist besonders praktisch, wenn mehrere Webseiten dasselbe Design verwenden sollen.

11. CSS-Selektoren

Selektoren legen fest, auf welche HTML-Elemente eine CSS-Regel angewendet wird.

Mehrere Elemente können mit einer gemeinsamen CSS-Regel gestaltet werden. 

h1, h2 {
    color: purple;
    font-family: Arial;
}

Wichtige CSS-Eigenschaften sind:

  • color: Textfarbe
  • background-color: Hintergrundfarbe
  • font-family: Schriftart
  • font-size: Schriftgröße
  • border: Rahmen

12. Vererbung in CSS

Bei der Vererbung übernehmen bestimmte untergeordnete HTML-Elemente Eigenschaften ihrer übergeordneten Elemente.

Beispielsweise kann die Schriftart, die für body festgelegt wurde, an enthaltene Elemente vererbt werden. 

body {
    font-family: Arial;
}

em {
    font-family: serif;
}

Nicht alle CSS-Eigenschaften werden vererbt. Außerdem können eigene CSS-Regeln die geerbten Werte überschreiben.

13. CSS-Klassen

Mit CSS-Klassen können bestimmte HTML-Elemente individuell gestaltet werden. Eine Klasse wird im HTML mit class angegeben und in CSS mit einem Punkt angesprochen. 

<p class="wichtig">Wichtiger Text</p>
    
.wichtig {
    color: red;
}

Dieselbe Klasse kann bei mehreren HTML-Elementen verwendet werden. Dadurch lassen sich Gestaltungsregeln wiederverwenden.

14. Zusammenspiel von CSS-Regeln

Für ein HTML-Element können mehrere CSS-Regeln gleichzeitig gelten. Welche Regel verwendet wird, hängt unter anderem von der Genauigkeit des Selektors und der Reihenfolge der Regeln ab.

Allgemeine Regeln können durch speziellere Regeln überschrieben werden. CSS-Kommentare werden mit /* und */ geschrieben.

15. Ausblick auf weitere CSS-Themen

Zum Abschluss wurden weitere Themen wie das Boxmodell, Layout und Positionierung angesprochen. Diese helfen dabei, das Aussehen und die Anordnung von Elementen genauer zu bestimmen.

Meine wichtigsten Erkenntnisse

  • Mit String-Methoden können Texte untersucht und bearbeitet werden.
  • Das DOM ermöglicht den Zugriff auf HTML-Elemente mit JavaScript.
  • Formulare ermöglichen die Eingabe und Verarbeitung von Daten.
  • HTML beschreibt die Struktur und Bedeutung einer Webseite.
  • CSS legt die Gestaltung der HTML-Elemente fest.
  • CSS-Klassen und Vererbung helfen, Webseiten übersichtlich und einheitlich zu gestalten.

Vorlesung 5 – JavaScript: Objekte

Vorlesung 5 – 02.11.2026

In dieser Vorlesung haben wir uns mit Objekten in JavaScript beschäftigt. Dabei ging es darum, wie Objekte aufgebaut sind, wie man sie erstellt und wie man mit ihren Eigenschaften und Methoden arbeitet.

1. Was sind Objekte?

Objekte spielen in JavaScript eine wichtige Rolle. Ein Objekt kann man sich wie einen Behälter vorstellen, der Daten und Funktionen zusammenfasst. Auch HTML-Elemente einer Webseite werden als Objekte dargestellt.

  • Eigenschaften (Attribute): Speichern Informationen über ein Objekt.
  • Methoden: Sind Funktionen, die zu einem Objekt gehören.
  • Members: Gemeinsamer Begriff für Eigenschaften und Methoden.

Beispiel: Ein Auto hat die Eigenschaft Farbe und die Methode fahren. Objekte können außerdem miteinander in Beziehung stehen.

2. Eigenschaften und Methoden verwenden

Auf Eigenschaften und Methoden kann man mit einem Punkt oder mit eckigen Klammern zugreifen. Methoden werden mit runden Klammern aufgerufen. 

let text = "JavaScript";

console.log(text.length);        // 10
console.log(text["length"]);     // 10
console.log(text.indexOf("Script")); // 4

length ist eine Eigenschaft und gibt die Anzahl der Zeichen an. indexOf() ist eine Methode und sucht nach einem bestimmten Text. Die Zählung beginnt bei 0.

3. Objekte erstellen

Manche Objekte sind bereits in JavaScript vorhanden. Andere müssen selbst erstellt werden. Dafür gibt es verschiedene Möglichkeiten:

  • Mit dem Konstruktor Object()
  • Mit Objekt-Literalen { }
  • Mit Konstruktorfunktionen und Prototypen
  • Mit der Klassenschreibweise class

3.1 Objekte mit Object() erstellen

Mit new Object() wird ein neues Objekt erzeugt. Anschließend können Eigenschaften und Methoden hinzugefügt werden. 

let person = new Object();

person.name = "Anna";

person.begruessung = function() {
    alert("Hallo " + this.name);
};

person.begruessung();

Die Eigenschaft name speichert den Namen. Die Methode begruessung() gibt eine Begrüßung aus. Mit this.name wird auf die Eigenschaft des aktuellen Objekts zugegriffen.

3.2 Objekt-Literale { }

Ein Objekt kann auch direkt mit geschweiften Klammern erstellt werden. Diese Schreibweise ist kürzer. Eigenschaften und Methoden werden durch Kommas getrennt. Zwischen Eigenschaftsname und Wert steht ein Doppelpunkt. 

let person = {
    name: "Anna",

    begruessung: function() {
        alert("Hallo " + this.name);
    }
};

person.begruessung();

4. JSON – JavaScript Object Notation

JSON ist ein Textformat, mit dem strukturierte Daten gespeichert und zwischen Server und Browser übertragen werden können. Es ähnelt der Objekt-Literal-Schreibweise, hat aber strengere Regeln.

JSON wird häufig bei Webanwendungen verwendet, die Daten nachladen, ohne die gesamte Webseite neu aufzubauen. Es ist eine Alternative zu XML.

Wichtige Regeln für JSON

  • Eigenschaftsnamen müssen in doppelten Anführungszeichen stehen.
  • Es dürfen nur unterstützte Datenwerte verwendet werden.
  • Funktionen und Funktionsaufrufe sind nicht erlaubt.
  • Kommentare sind nicht erlaubt.
{
    "name": "Anna",
    "alter": 21,
    "studentin": true
}

JSON.stringify() und JSON.parse()

JSON.stringify() wandelt JavaScript-Daten in einen JSON-String um. JSON.parse() wandelt einen JSON-String wieder in JavaScript-Daten um. 

let person = { name: "Anna", alter: 21 };

let text = JSON.stringify(person);

let objekt = JSON.parse(text);

console.log(objekt.name); // Anna

Beim Datentransfer kann der Server JSON-Text senden. Der Browser kann diesen mit JSON.parse() in ein JavaScript-Objekt umwandeln und weiterverarbeiten.

5. Konstruktorfunktionen

Konstruktorfunktionen werden verwendet, wenn mehrere Objekte mit dem gleichen Aufbau erstellt werden sollen. Die Eigenschaften können dabei unterschiedliche Werte haben.

Konstruktorfunktionen werden üblicherweise mit einem Großbuchstaben benannt und mit new aufgerufen. 

function Person(name) {
    this.name = name;

    this.begruessung = function() {
        alert("Hallo " + this.name);
    };
}

let person1 = new Person("Anna");
let person2 = new Person("Max");

person1.begruessung();
person2.begruessung();

Beide Objekte besitzen die gleiche Struktur, speichern aber unterschiedliche Namen. Mit this.name wird die Eigenschaft des jeweiligen Objekts festgelegt.

6. Klassen in JavaScript

Klassen sind eine weitere Möglichkeit, Objekte mit einem gemeinsamen Aufbau zu erstellen. Eine Klasse wird mit class definiert. Mit new wird daraus ein Objekt erzeugt.

Der Konstruktor einer Klasse heißt constructor(). Er wird beim Erstellen eines Objekts automatisch aufgerufen. Wird kein eigener Konstruktor angegeben, gibt es einen Standardkonstruktor. 

class Hund {
    constructor() {
        this.type = "Dackel";
    }

    printType() {
        console.log(this.type);
    }
}

let hund = new Hund();
hund.printType(); // Dackel

Eigenschaften können im Konstruktor festgelegt werden. Methoden werden innerhalb der Klasse definiert. Mit this greift man auf das aktuelle Objekt zu.

7. Vererbung mit extends und super()

Durch Vererbung kann eine Klasse Eigenschaften und Methoden einer anderen Klasse übernehmen. Dafür wird das Schlüsselwort extends verwendet.

Wenn die abgeleitete Klasse einen eigenen Konstruktor besitzt, muss zuerst super() aufgerufen werden, bevor auf this zugegriffen wird. 

class Tier {
    constructor(name) {
        this.name = name;
    }
}

class Hund extends Tier {
    constructor(name) {
        super(name);
    }
}

let hund = new Hund("Bello");
console.log(hund.name); // Bello

8. this und der Funktionskontext

Das Schlüsselwort this bezieht sich auf einen bestimmten Ausführungskontext. Bei einem normalen Methodenaufruf zeigt this auf das Objekt, über das die Methode aufgerufen wird. 

let person = {
    name: "Max",

    getName: function() {
        return this.name;
    }
};

console.log(person.getName()); // Max

Anders als bei Java hängt der Wert von this in JavaScript häufig davon ab, wie eine Funktion aufgerufen wird.

  • Objektmethode: this bezieht sich auf das aufrufende Objekt.
  • Konstruktorfunktion mit new: this bezieht sich auf das neu erzeugte Objekt.
  • Normale globale Funktion: this hängt vom Modus und der Umgebung ab.
  • Pfeilfunktion: Übernimmt this aus ihrem umgebenden Kontext.

Besonders bei Callbacks oder beim Weitergeben von Methoden kann der ursprüngliche Bezug zu einem Objekt verloren gehen.

9. Funktionen mit bind() verbinden

Mit bind() kann eine Funktion dauerhaft an ein bestimmtes Objekt gebunden werden. Dadurch bleibt der gewünschte this-Bezug erhalten, auch wenn die Funktion an anderer Stelle aufgerufen wird. 

class Hund {
    constructor() {
        this.type = "Dackel";
    }

    printType() {
        console.log(this.type);
    }
}

let hund = new Hund();

let funktion = hund.printType.bind(hund);

funktion(); // Dackel

Ohne bind() kann bei der Weitergabe einer Methode der Objektbezug verloren gehen. Pfeilfunktionen verwenden dagegen den umgebenden this-Kontext und benötigen deshalb in diesem Fall kein bind().

10. Kapselung und private Eigenschaften

Kapselung bedeutet, dass bestimmte Daten eines Objekts vor dem direkten Zugriff von außen geschützt werden. Der Zugriff soll über dafür vorgesehene Methoden erfolgen.

10.1 Private Variablen in Konstruktorfunktionen

Eine Möglichkeit besteht darin, lokale Variablen innerhalb einer Konstruktorfunktion zu verwenden. Diese können nicht direkt von außen gelesen werden.

Methoden, die innerhalb der Konstruktorfunktion definiert werden und auf diese Variablen zugreifen, heißen privilegierte öffentliche Methoden. Häufig werden dafür Getter und Setter verwendet. 

function Person(name) {
    let privaterName = name;

    this.getName = function() {
        return privaterName;
    };

    this.setName = function(neuerName) {
        privaterName = neuerName;
    };
}

let person = new Person("Anna");

console.log(person.getName()); // Anna
person.setName("Max");

Getter lesen einen Wert aus. Setter verändern einen Wert. Öffentliche Methoden auf dem Prototyp können nicht direkt auf lokale private Variablen des Konstruktors zugreifen.

10.2 Echte private Eigenschaften mit #

Seit ES2022 unterstützt JavaScript echte private Eigenschaften und Methoden. Diese werden mit einem # vor dem Namen gekennzeichnet. 

class Person {
    #name;

    constructor(name) {
        this.#name = name;
    }

    getName() {
        return this.#name;
    }

    setName(name) {
        this.#name = name;
    }
}

let person = new Person("Anna");

console.log(person.getName()); // Anna

Auf #name kann nur innerhalb der Klasse zugegriffen werden. Ein direkter Zugriff von außen führt zu einem Syntaxfehler.

Auch Methoden können mit # als privat gekennzeichnet werden. Sie können dann nur innerhalb der Klasse aufgerufen werden.

11. Rest-Parameter

Mit drei Punkten (...) können mehrere übergebene Werte in einem Array gesammelt werden. Das nennt man Rest-Parameter. 

function ausgabe(erstes, ...weitere) {
    console.log(erstes);
    console.log(weitere);
}

ausgabe(1, 2, 3, 4);

// erstes: 1
// weitere: [2, 3, 4]

12. Destructuring

Beim Destructuring können einzelne Werte aus Arrays oder Eigenschaften aus Objekten direkt in Variablen übernommen werden. Dadurch wird der Code kürzer und übersichtlicher.

12.1 Array Destructuring

let [a, b] = [10, 20];

console.log(a); // 10
console.log(b); // 20

12.2 Object Destructuring

let person = {
    name: "Anna",
    alter: 21
};

let { name, alter } = person;

console.log(name);  // Anna
console.log(alter); // 21

Die Variablennamen entsprechen dabei den Eigenschaftsnamen des Objekts. Statt jede Eigenschaft einzeln auszulesen, können mehrere Werte gleichzeitig übernommen werden.

12.3 Rest-Syntax beim Destructuring

Mit ...rest werden die übrigen Werte oder Eigenschaften gesammelt. 

let person = {
    name: "Anna",
    alter: 21,
    stadt: "Mannheim"
};

let { name, ...rest } = person;

console.log(name); // Anna
console.log(rest);
// {alter: 21, stadt: "Mannheim"}

Destructuring kann auch in Schleifen und direkt in Funktionsparametern verwendet werden.

13. Object Literal Enhancement

Object Literal Enhancement ist eine vereinfachte Schreibweise zum Erstellen von Objekten aus bereits vorhandenen Variablen. Haben Variable und Eigenschaft denselben Namen, muss dieser nur einmal geschrieben werden. 

let name = "Zugspitze";
let hoehe = 2962;

let berg = { name, hoehe };

console.log(berg);

Auch Funktionen können auf diese Weise zu einem Objekt hinzugefügt werden. Das ist gewissermaßen das Gegenstück zum Destructuring.

14. Spread-Operator

Der Spread-Operator verwendet ebenfalls drei Punkte (...). Er kann die Elemente eines Arrays oder die Eigenschaften eines Objekts in eine neue Struktur übernehmen.

Arrays zusammenführen

let tiere1 = ["Hund", "Katze"];
let tiere2 = ["Löwe", "Maus"];

let alleTiere = [...tiere1, ...tiere2];

console.log(alleTiere);

Objekte zusammenführen

let morgens = {
    fruehstueck: "Brot",
    brunch: "Brezel"
};

let mahlzeiten = {
    ...morgens,
    mittag: "Pizza"
};

console.log(mahlzeiten);

Dabei entsteht eine neue Struktur. Die ursprünglichen Arrays oder Objekte werden durch diesen Vorgang nicht direkt verändert. Bei verschachtelten Daten handelt es sich allerdings nur um eine flache Kopie.

Meine wichtigsten Erkenntnisse

  • Objekte fassen Eigenschaften und Methoden zusammen.
  • Mit Konstruktoren und Klassen lassen sich mehrere ähnliche Objekte erstellen.
  • JSON wird verwendet, um strukturierte Daten zu übertragen.
  • Mit extends können Klassen voneinander erben.
  • this hängt in JavaScript vom jeweiligen Funktionskontext ab.
  • bind() kann den this-Bezug einer Funktion festlegen.
  • Private Eigenschaften schützen Daten vor direktem Zugriff.
  • Destructuring und der Spread-Operator vereinfachen die Arbeit mit Daten.

Neu für mich waren vor allem JSON, der Umgang mit this und bind() sowie private Eigenschaften. Außerdem habe ich verstanden, wie Destructuring und der Spread-Operator den JavaScript-Code übersichtlicher machen können.

Vorlesung 6 – DOM und jQuery

Vorlesung 6 – 09.11.2026

In dieser Vorlesung haben wir gelernt, wie man HTML-Elemente mit JavaScript verändern kann. Außerdem haben wir die JavaScript-Bibliothek jQuery kennengelernt, mit der viele Aufgaben einfacher und kürzer geschrieben werden können.

1. Webseiten dynamisch verändern

Mit JavaScript können Webseiten verändert werden, ohne dass die gesamte Seite neu geladen werden muss. Man kann zum Beispiel Texte hinzufügen, Bilder ausblenden oder das Aussehen von Elementen ändern.

Dabei gibt es zwei wichtige Schritte:

  1. Das gewünschte HTML-Element finden.
  2. Das Element verändern oder Informationen auslesen.

Mögliche Änderungen sind das Hinzufügen und Entfernen von CSS-Klassen, das Ändern von Eigenschaften, das Einfügen neuer Inhalte und das Entfernen von Elementen.

2. Document Object Model (DOM)

DOM steht für Document Object Model. Es ist eine interne Darstellung der HTML-Seite im Browser. Der Browser speichert dabei die HTML-Elemente, Attribute und Texte in einer Baumstruktur.

Die einzelnen Bestandteile heißen Knoten. Das DOM ist selbst keine Programmiersprache, sondern ein Standard, über den JavaScript auf die Webseite zugreifen kann.

Beziehungen zwischen Knoten

  • Elternknoten: Enthält andere Knoten.
  • Kindknoten: Liegt direkt innerhalb eines Elternknotens.
  • Geschwisterknoten: Haben denselben Elternknoten.
  • Textknoten: Enthält den Text eines Elements.

3. HTML-Elemente mit JavaScript auswählen

Um ein Element zu verändern, muss man es zuerst finden. Dafür gibt es verschiedene DOM-Methoden.

getElementById()

Diese Methode sucht ein einzelnes Element anhand seiner eindeutigen ID. 

let titel = document.getElementById("titel");

getElementsByTagName()

Diese Methode sucht alle Elemente mit einem bestimmten HTML-Tag. Das Ergebnis ist eine Sammlung von Elementen, auf die man über einen Index zugreifen kann. 

let absaetze = document.getElementsByTagName("p");

console.log(absaetze.length);
console.log(absaetze[0]);

Beide Methoden können auch kombiniert werden, um beispielsweise nur die Absätze innerhalb eines bestimmten Bereichs zu finden.

4. Durch die DOM-Struktur navigieren

Mit verschiedenen Eigenschaften kann man zwischen benachbarten Knoten wechseln.

  • childNodes: Enthält die direkten Kindknoten.
  • parentNode: Gibt den direkten Elternknoten zurück.
  • nextSibling: Gibt den nächsten Geschwisterknoten zurück.
  • previousSibling: Gibt den vorherigen Geschwisterknoten zurück.
  • nodeValue: Kann den Inhalt eines Textknotens liefern.

Wenn ein gesuchter Geschwisterknoten nicht existiert, wird null zurückgegeben. Auch Leerzeichen und Zeilenumbrüche können als Textknoten vorkommen. Dadurch kann die Navigation im DOM kompliziert werden.

5. Inhalte mit innerHTML verändern

Mit innerHTML kann man den HTML-Inhalt eines Elements lesen oder ersetzen. Es können sowohl Texte als auch HTML-Tags eingefügt werden. 

let titel = document.getElementById("titel");

titel.innerHTML = "Neue Überschrift";

Die ältere Methode document.write() kann beim Laden einer Seite Inhalte ausgeben. Für spätere Änderungen an einer bereits geladenen Webseite ist sie jedoch ungeeignet.

6. Warum JavaScript-Bibliotheken?

Die direkte Arbeit mit dem DOM kann aufwendig sein. Man muss häufig viele einzelne Schritte schreiben. Außerdem gab es besonders bei älteren Browsern Unterschiede in der Verarbeitung des DOM.

JavaScript-Bibliotheken stellen fertige Funktionen für wiederkehrende Aufgaben bereit. Dadurch benötigt man weniger eigenen Code.

Beispiele aus der Vorlesung sind jQuery, Prototype, MooTools, Dojo Toolkit und die Yahoo User Interface Library.

7. Was ist jQuery?

jQuery ist eine JavaScript-Bibliothek, die den Zugriff auf HTML-Elemente und die Bearbeitung von Webseiten vereinfacht.

Mit jQuery kann man beispielsweise:

  • HTML-Elemente mit Selektoren auswählen.
  • CSS-Klassen hinzufügen oder entfernen.
  • Texte und Attribute verändern.
  • Elemente ein- und ausblenden.
  • Auf Benutzeraktionen reagieren.
  • Animationen und Effekte verwenden.

Vorteile von jQuery sind die vergleichsweise kurze Schreibweise, die Wiederverwendung fertiger Funktionen und die große Auswahl an Erweiterungen, sogenannten Plug-ins. Die Bibliothek ist kostenlos.

8. jQuery einbinden

Um jQuery zu verwenden, muss die Bibliothek zuerst als JavaScript-Datei in die HTML-Seite eingebunden werden. 

<script src="js/jquery.js"></script>

Danach kann man eigene JavaScript-Anweisungen schreiben, die jQuery verwenden. Die Bibliothek muss dabei vor dem eigenen jQuery-Code geladen werden.

9. jQuery-Selektoren

jQuery verwendet die Kurzschreibweise $(). Innerhalb der Klammern steht meistens ein Selektor, mit dem HTML-Elemente ausgewählt werden. 

$("p")          // Alle Absätze
$("#titel")     // Element mit der ID titel
$(".wichtig")   // Elemente mit der Klasse wichtig
$("#box p")     // Absätze innerhalb von #box

Die Auswahl wird als jQuery-Objekt gespeichert. Dieses enthält eine Sammlung ausgewählter HTML-Elemente, die auch Collection genannt wird.

Weitere Selektoren

jQuery kann auch nach Attributen und bestimmten Textinhalten suchen. 

$("a[href^='http://']")

$("p:contains('Hallo')")

Der erste Selektor wählt Links aus, deren href-Wert mit http:// beginnt. Der zweite wählt Absätze aus, die den Text Hallo enthalten.

10. document.ready()

Mit ready() kann festgelegt werden, dass der jQuery-Code erst ausgeführt wird, wenn die HTML-Struktur der Seite geladen ist. Dadurch können die benötigten Elemente bereits ausgewählt werden. 

$(document).ready(function() {
    $("p").addClass("wichtig");
});

In diesem Beispiel bekommen alle p-Elemente die CSS-Klasse wichtig.

11. jQuery-Methoden verketten

Viele jQuery-Methoden geben wieder ein jQuery-Objekt zurück. Deshalb können mehrere Methoden direkt hintereinander aufgerufen werden. Dies nennt man Verkettung oder Chaining. 

$("p").addClass("wichtig").hide();

Hier wird den Absätzen zuerst eine Klasse hinzugefügt. Danach werden sie ausgeblendet.

Drei Gruppen von jQuery-Methoden

  • Transparente Methoden: Geben die gleiche Collection zurück. Die ausgewählten Elemente bleiben erhalten.
  • Destruktive Methoden: Geben eine veränderte Collection zurück, beispielsweise eine kleinere Auswahl.
  • Terminierende Methoden: Geben keinen jQuery-Objektwert zurück, sondern beispielsweise einen String. Damit endet die jQuery-Verkettung.

12. Mehrere Elemente mit each() bearbeiten

Viele jQuery-Methoden bearbeiten automatisch alle Elemente einer Auswahl. Wenn für jedes Element eigene Anweisungen ausgeführt werden sollen, verwendet man each(). 

$("p").each(function() {
    console.log("Absatz gefunden");
});

Die Funktion innerhalb von each() wird für jedes ausgewählte Element einmal ausgeführt.

13. Anonyme Funktionen

Eine anonyme Funktion ist eine Funktion ohne eigenen Namen. Sie wird häufig als Argument an eine andere Funktion übergeben. 

function() {
    // Anweisungen
}

Bei each() wird eine solche Funktion für jedes Element der Auswahl aufgerufen.

14. this und $(this)

Innerhalb einer normalen Callback-Funktion von each() bezeichnet this das aktuelle HTML-Element, das gerade bearbeitet wird.

this ist dabei ein normales DOM-Element. Mit $(this) wird daraus ein jQuery-Objekt, auf das jQuery-Methoden angewendet werden können. 

$("p").each(function() {
    $(this).addClass("wichtig");
});

In diesem Beispiel erhält jeder ausgewählte Absatz die Klasse wichtig.

15. Wichtige jQuery-Methoden

  • addClass(): Fügt eine CSS-Klasse hinzu.
  • removeClass(): Entfernt eine CSS-Klasse.
  • attr(): Liest oder verändert ein HTML-Attribut.
  • append(): Fügt Inhalt am Ende eines Elements ein.
  • before(): Fügt Inhalt vor einem Element ein.
  • clone(): Erstellt eine Kopie eines Elements.
  • hide(): Blendet ein Element aus.
  • fadeOut(): Lässt ein Element langsam verschwinden.

16. Elemente kopieren und verändern

Mit clone() kann ein HTML-Element einschließlich seines Inhalts kopiert werden. Die Kopie kann danach verändert werden, bevor sie in die Webseite eingefügt wird. 

let kopie = $(".wichtig").first().clone();

kopie.removeClass("wichtig");
kopie.addClass("hinweis");

Die CSS-Klassen bestimmen das Aussehen des kopierten Elements. Erst durch das Einfügen in die Webseite, beispielsweise mit before(), wird die Kopie dort sichtbar.

17. Entwicklertools im Browser

Mit den Entwicklertools eines Browsers kann man den aktuellen Zustand der Webseite untersuchen und JavaScript-Fehler finden.

Der ursprüngliche Seitenquelltext zeigt nicht unbedingt alle Änderungen, die JavaScript später am DOM vorgenommen hat. Diese lassen sich in den Entwicklertools untersuchen.

Meine wichtigsten Erkenntnisse

  • Das DOM stellt HTML als Baumstruktur dar.
  • JavaScript kann HTML-Elemente auswählen und verändern.
  • jQuery vereinfacht viele Aufgaben bei der Webprogrammierung.
  • Mit Selektoren können bestimmte Elemente gefunden werden.
  • Viele jQuery-Methoden lassen sich miteinander verketten.
  • each() führt eine Funktion für jedes ausgewählte Element aus.
  • this bezeichnet bei each() das aktuelle DOM-Element.
  • Mit $(this) kann man jQuery-Methoden darauf anwenden.

Neu für mich war vor allem jQuery. Ich habe gelernt, dass man damit viele Änderungen an einer Webseite mit weniger Code durchführen kann. Besonders wichtig fand ich die Selektoren, die each()-Methode und den Unterschied zwischen this und $(this).

Vorlesung 7 – JavaScript Events, jQuery Events und Window-Objekt

Vorlesung 7-1: JavaScript Events und jQuery Events

1. Ereignisgesteuerte Programmierung

Bei der ereignisgesteuerten Programmierung wird eine Funktion ausgeführt, sobald ein bestimmtes Ereignis (Event) eintritt. Solche Ereignisse entstehen zum Beispiel, wenn ein Benutzer auf einen Button klickt, eine Taste drückt oder etwas in ein Eingabefeld schreibt.

  • Event: Ein Ereignis, beispielsweise ein Mausklick.
  • Event-Handler: Eine Funktion, die auf das Ereignis reagiert.
  • Event-Queue: Eine Warteschlange für ausgelöste Ereignisse.
  • Event-Loop: Prüft fortlaufend, ob Ereignisse verarbeitet werden müssen.

Ereignisse werden in einer Warteschlange gesammelt und anschließend verarbeitet. Dadurch kann eine Webseite auf Benutzeraktionen reagieren.

2. Events mit JavaScript behandeln

Damit eine Webseite auf eine Benutzeraktion reagieren kann, sind drei Schritte notwendig:

  1. Das gewünschte HTML-Element auswählen.
  2. Festlegen, auf welches Ereignis reagiert werden soll.
  3. Eine Funktion bestimmen, die beim Ereignis ausgeführt wird.

In JavaScript gibt es drei Möglichkeiten, Events zu behandeln:

  • HTML-Event-Handler: Das Ereignis wird direkt im HTML-Element angegeben, beispielsweise mit onclick. Dabei werden HTML und JavaScript vermischt.
  • DOM-Event-Handler: Das Ereignis wird im JavaScript-Code zugewiesen, zum Beispiel mit element.onclick. Hier kann pro Ereignis nur eine Funktion direkt zugewiesen werden.
  • DOM-Event-Listener: Mit addEventListener() können einem Element mehrere Funktionen für dasselbe Ereignis zugeordnet werden. Diese Methode wird empfohlen.

Beispiel für einen Event-Listener:

const button = document.getElementById("meinButton");

button.addEventListener("click", function() {
    alert("Button wurde geklickt!");
});

Die Funktion wird erst ausgeführt, wenn der Benutzer auf den Button klickt. Statt einer normalen Funktion kann auch eine Arrow-Funktion verwendet werden.

3. Wichtige JavaScript-Events

Je nach Benutzeraktion werden unterschiedliche Ereignisse ausgelöst.

Mausereignisse:

  • click – ein Element wird angeklickt.
  • dblclick – ein Element wird doppelt angeklickt.
  • mousedown – eine Maustaste wird gedrückt.
  • mouseup – eine Maustaste wird losgelassen.
  • mousemove – die Maus wird bewegt.
  • mouseover und mouseout – die Maus bewegt sich über ein Element oder verlässt es.
  • mouseenter und mouseleave – die Maus betritt oder verlässt ein Element, ohne dass Bewegungen zwischen Kindelementen erneut zählen.
  • contextmenu – das Kontextmenü wird aufgerufen.

Tastaturereignisse:

  • keydown – eine Taste wird gedrückt.
  • keyup – eine Taste wird losgelassen.
  • keypress – älteres Ereignis für Tasteneingaben.

Formularereignisse:

  • input – der Wert eines Eingabefeldes verändert sich.
  • change – eine Änderung wird übernommen.
  • submit – ein Formular wird abgeschickt.
  • reset – ein Formular wird zurückgesetzt.

Weitere Ereignisse:

  • focus und blur – ein Element erhält oder verliert den Fokus.
  • load – eine Seite oder Ressource wurde geladen.
  • resize – die Fenstergröße verändert sich.
  • scroll – die Seite wird gescrollt.
  • DOMContentLoaded – das HTML-Dokument wurde eingelesen.

4. Das Event-Objekt

Bei einem Ereignis stellt JavaScript zusätzliche Informationen über das Event bereit. Diese Informationen befinden sich im Event-Objekt.

  • type – Art des Ereignisses.
  • target – Element, auf dem das Ereignis ausgelöst wurde.
  • clientX und clientY – Mausposition innerhalb des sichtbaren Browserbereichs.
  • screenX und screenY – Mausposition auf dem Bildschirm.
  • button – verwendete Maustaste.
  • altKey, ctrlKey und shiftKey – zeigen an, ob bestimmte Zusatztasten gedrückt wurden.
  • relatedTarget – ein weiteres beteiligtes Element bei bestimmten Mausereignissen.

Mit preventDefault() kann eine normale Browseraktion verhindert werden, beispielsweise das Abschicken eines Formulars. Mit stopPropagation() kann die Weitergabe eines Ereignisses an andere Elemente gestoppt werden.

5. Events mit jQuery

jQuery vereinfacht die Ereignisbehandlung. HTML-Elemente können über Selektoren ausgewählt und mit Funktionen verbunden werden.

Beispiel:

$("#meinButton").on("click", function() {
    alert("Hallo!");
});

Mit on() wird ein Event-Handler registriert. Die Methode off() kann einen registrierten Event-Handler wieder entfernen.

Außerdem bietet jQuery Kurzschreibweisen für bestimmte Ereignisse. Mit $(document).ready() kann festgelegt werden, dass der Code erst ausgeführt wird, wenn das HTML-Dokument bereit ist.

Vorlesung 7-2: Window-Objekt und interaktive Navigation

1. Browser Object Model (BOM)

Neben dem Document Object Model (DOM) gibt es das Browser Object Model (BOM). Während das DOM den Inhalt einer Webseite beschreibt, ermöglicht das BOM den Zugriff auf bestimmte Funktionen und Informationen des Browsers.

Das wichtigste Objekt ist window. Es repräsentiert ein Browserfenster beziehungsweise einen Browsertab. Über dieses Objekt kann JavaScript beispielsweise Fensterinformationen auslesen, neue Fenster öffnen und die Navigation beeinflussen.

2. Wichtige Objekte des BOM

  • window – stellt das aktuelle Browserfenster dar.
  • document – ermöglicht den Zugriff auf die HTML-Seite und ihre Elemente.
  • location – enthält Informationen über die aktuelle URL und ermöglicht Navigation.
  • history – ermöglicht den Zugriff auf den Browserverlauf, beispielsweise Vor- und Zurückgehen.
  • navigator – liefert Informationen über den Browser.
  • screen – enthält Informationen über den Bildschirm, beispielsweise seine Größe.

Über das Window-Objekt sind auch weitere Browserfunktionen und Web-APIs erreichbar. Beispiele sind die Geolocation API und die Storage API.

3. Größe und Position eines Browserfensters

Mit JavaScript lassen sich die Größe und die Position eines Fensters bestimmen.

  • innerWidth – Breite des sichtbaren Inhaltsbereichs.
  • innerHeight – Höhe des sichtbaren Inhaltsbereichs.
  • outerWidth – gesamte Breite des Browserfensters.
  • outerHeight – gesamte Höhe des Browserfensters.
  • screenX und screenY – Position des Fensters auf dem Bildschirm.
  • scrollX und scrollY – aktuelle Scrollposition.

Der sichtbare Bereich einer Webseite wird auch Viewport genannt. Er ist nicht immer genauso groß wie das gesamte HTML-Dokument, da die Seite länger oder breiter sein kann.

4. Methoden zur Fenstersteuerung

Das Window-Objekt stellt verschiedene Methoden bereit:

  • window.open() – öffnet ein neues Browserfenster oder einen Tab.
  • window.close() – versucht, ein durch JavaScript geöffnetes Fenster zu schließen.
  • window.moveTo() – verschiebt ein Fenster an eine bestimmte Position.
  • window.moveBy() – verschiebt ein Fenster relativ zur aktuellen Position.
  • window.resizeTo() – verändert die Fenstergröße auf bestimmte Werte.
  • window.resizeBy() – verändert die Fenstergröße relativ zur bisherigen Größe.
  • window.scrollTo() – scrollt zu einer bestimmten Position.
  • window.scrollBy() – scrollt um einen bestimmten Abstand.
  • window.focus() – versucht, das Fenster in den Vordergrund zu bringen.
  • window.blur() – entfernt den Fokus vom Fenster.

Viele Funktionen zur Fenstersteuerung sind in modernen Browsern aus Sicherheits- und Benutzerfreundlichkeitsgründen eingeschränkt.

5. Neue Browserfenster öffnen

Mit window.open() kann eine Webseite in einem neuen Fenster geöffnet werden. Dabei können unter anderem eine URL, ein Fenstername und zusätzliche Fenstereigenschaften angegeben werden.

Beispiel:

window.open(
    "https://www.dhbw-mannheim.de",
    "DHBW",
    "width=600,height=400"
);

Zu den möglichen Einstellungen gehören width, height, left, top, resizable und scrollbars. Ob diese Einstellungen tatsächlich berücksichtigt werden, hängt vom Browser ab.

6. Fenstergröße und Dokumentgröße mit jQuery

Mit den jQuery-Methoden width() und height() können die Maße eines Fensters oder Dokuments ermittelt werden. 

$(window).width();
$(window).height();

$(document).width();
$(document).height();

Wichtig: Die Fenstergröße beschreibt den sichtbaren Bereich. Die Dokumentgröße beschreibt dagegen die gesamte Webseite. Deshalb kann die Dokumenthöhe größer sein als die Fensterhöhe.

Mit width(300) oder width("300px") kann bei einem geeigneten HTML-Element auch eine Breite gesetzt werden.

7. Interaktive Navigation mit jQuery

Lange Webseiten können schnell unübersichtlich werden. Deshalb gibt es verschiedene Möglichkeiten, Informationen platzsparend darzustellen.

  • Akkordeon: Inhalte werden in aufklappbaren Bereichen angezeigt.
  • Tabbed Panels: Inhalte werden über verschiedene Registerkarten aufgerufen.
  • Tooltips: Zusätzliche Informationen erscheinen beispielsweise beim Berühren eines Elements mit der Maus.
  • Sortierbare Tabellen: Daten können durch einen Klick auf eine Spaltenüberschrift sortiert werden.

8. Akkordeon mit jQuery

Ein Akkordeon ist eine Navigationsmöglichkeit, bei der Inhalte zunächst verborgen sind. Klickt man auf eine Überschrift, wird der dazugehörige Inhalt angezeigt. Dadurch bleibt die Webseite übersichtlich.

In der Vorlesung wurde dafür das jQuery-UI-Accordion-Plugin behandelt. Neben der jQuery-Bibliothek werden dafür die Dateien ui.core.js und ui.accordion.js verwendet.

Ein Akkordeon besteht aus einem Container, mehreren Überschriften und den dazugehörigen Inhaltsbereichen. Die Überschriften dienen als anklickbare Register.

Beispiel für die Aktivierung:

$(document).ready(function() {
    $("#akkordeon").accordion({
        header: "h2"
    });
});

Der Selektor #akkordeon wählt den Container mit der entsprechenden ID aus. Mit accordion() wird der Akkordeon-Effekt aktiviert. Die Einstellung header: "h2" legt fest, dass die h2-Überschriften als Register verwendet werden.

Mit der Option active kann festgelegt werden, welcher Bereich zuerst geöffnet sein soll. Über selectedClass lässt sich dem ausgewählten Register eine CSS-Klasse zuweisen, damit es anders gestaltet werden kann.
